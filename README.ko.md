# MealBudgetPlanner

한 달 식비 예산을 입력하면 끼니별 허용 금액과 소비 패턴 피드백을 매일 제공하는 식비 관리 앱입니다. 월급날 식비 예산을 세워도 월말에 항상 초과한다면? 배달앱 내역은 흩어져 있고, 한 끼에 얼마를 써야 예산 내에 있는지 실시간으로 모를 때 사용하는 앱입니다.

## 기술 스택

- React 18.0.0
- TypeScript
- Vitest
