# MealBudgetPlanner

## Platform
앱인토스 (Vite + React + TDS)

## One-liner
한 달 식비 예산을 입력하면 끼니별 허용 금액과 소비 패턴 피드백을 매일 제공하는 식비 관리 앱

## Problem
월급날 식비 예산을 세워도 월말에 항상 초과한다. 배달앱 내역은 흩어져 있고, 한 끼에 얼마를 써야 예산 내에 있는지 실시간으로 모른다.

## Target Users
1인 가구 또는 2인 가구 20-35세. 배달음식 지출이 많고 월말 식비 초과를 반복 경험하는 직장인.

## Core Features
1. 월 식비 예산 설정 + 오늘 남은 끼니별 허용 금액 자동 계산 (예: '오늘 저녁까지 8,400원')
2. 식사 기록 입력 (금액+카테고리: 배달/직접조리/외식) — 3탭 이내
3. 일일 체크인: 오늘 식사 기록하면 배너 광고 후 '이번 달 페이스' 배지 지급
4. 주간 소비 패턴 분석 (배달 vs 외식 vs 직접조리 비율 도넛차트)
5. 리워드 광고 시청 후 '월간 식비 절약 가능 금액 시뮬레이션' 결과 공개
6. 예산 초과 경고 푸시 (토스 인앱 알림)

## Monetization
- Model: ads
- Estimated MRR: 3200000
- Reasoning: 일일 체크인 구조로 DAU 유지가 핵심. 식비 기록은 매일 동기가 있음. DAU 4,000 보수 추정. 배너: 4,000×2×30×1$/1000×1350×0.85 ≈ 27.5만원. 리워드(주간 분석 게이팅): 4,000×0.18×30×4$/1000×1350×0.85 ≈ 111만원. 월 약 138만원. 성장 반영 320만원은 3개월 안정화 목표치.
